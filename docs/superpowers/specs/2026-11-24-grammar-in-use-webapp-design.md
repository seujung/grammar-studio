# Grammar in Use Studio 설계 문서

- 작성일: 2026. 11. 24.
- 대상 저장소: `grammer-in-use-edu`

## 1. 목표와 범위

### 목표
- 중급 영어 학습자가 *English Grammar in Use (3rd Ed.)*의 145개 단원 체계를 따라 문법을 학습합니다.
- 16문항 진단 테스트로 취약 문법 영역을 찾고, 추천 단원부터 바로 공부합니다.
- 개념 설명, 비교표, 4가지 연습 문제, 간격 반복 복습(SRS), 음성 듣기(TTS)를 한 화면 흐름에서 제공합니다.
- 백엔드 서버 없이 GitHub Pages에서 정적 웹 앱으로 배포합니다.

### 비목표
- 회원가입과 원격 데이터베이스 기반 동기화는 구현하지 않습니다.
- 음성 인식(STT) 기반 말하기 채점은 구현하지 않습니다.

### 하지 않는 일
- 저작권이 있는 PDF 원문과 스캔 이미지는 저장소에 커밋하거나 배포하지 않습니다.
- `.gitignore`에 `reference/*.pdf`를 등록해 PDF 파일이 Git 추적 대상에 들어가지 않도록 차단합니다.

## 2. 구현 방식 비교

1. **방식 1(선택): 145개 단원 체계 + 핵심 32개 단원 심화**
   - 16개 영역, 145개 단원 전체 목차와 진단 테스트를 제공합니다.
   - 16개 영역마다 핵심 단원 2개씩 총 32개 단원에 심화 개념(A~C), 비교표, 자주 하는 실수, 연습 문제 8문항을 담습니다.
   - 나머지 113개 단원은 핵심 요약 카드와 연관 심화 단원 링크를 제공합니다.
2. **방식 2: 145개 전 단원 경량 완성**
   - 모든 단원에 짧은 요약과 단순 객관식만 채우는 방식입니다. 개념 대조와 복합 연습이 약해 선택하지 않았습니다.
3. **방식 3: 일일 5분 퀴즈 중심**
   - 단원 목록 없이 퀴즈만 푸는 방식입니다. 체계적 문법 참고 기능이 약해 선택하지 않았습니다.

## 3. 아키텍처

- **프론트엔드**: React 19, TypeScript, Vite, Tailwind CSS v4, `react-router-dom`(`HashRouter`).
- **상태 저장**: `localStorage`에 학습 진도, SRS 카드, 진단 결과, 설정을 저장하고 JSON 파일로 백업·복원합니다.
- **채점기**: 대소문자, 문장 끝 부호, 영어 축약형(`I'm` / `I am`, `isn't` / `is not`, `'d`, `'s`)을 정규화해 모두 정답으로 인정합니다.
- **복습 큐**: SM-2 간격(`1 -> 3 -> 7 -> 14 -> 30일`)으로 틀린 문제와 완료 단원을 예약합니다.
- **배포**: GitHub Actions(`.github/workflows/deploy.yml`)로 빌드와 테스트 후 GitHub Pages에 배포합니다.
